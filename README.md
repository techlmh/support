# 🏫 관내 학교 지원장학 요청서 일괄 분석 및 부서 분류 시스템

관내 유·초·중·고등학교에서 제출한 지원장학 요청서(Excel)를 일괄 업로드하여 핵심 항목을 자동 추출하고, 강서양천교육지원청 9개 과의 업무 기준에 따라 내용을 자동 분류·정렬해 주는 웹 애플리케이션입니다.

별도의 백엔드 서버 설치 없이 **GitHub Pages(WebAssembly 기반 stlite)** 환경에서 100% 브라우저 클라이언트 사이드로 구동됩니다. 코드 간섭을 방지하기 위해 구동 환경(`index.html`)과 분석 로직(`app.py`)이 분리되어 안정적으로 동작합니다.

---

## 📌 주요 기능

1. **다중 엑셀 파일 일괄 처리 (Multi-file Upload)**
   - 관내 다수 학교의 서식 파일(`.xlsx`, `.xls`)을 드래그 앤 드롭으로 한 번에 업로드 및 데이터 파싱
2. **핵심 데이터 자동 추출**
   - 학교명 및 학교급(고등/중/초등/유치원/특수) 자동 판별
   - 담당 장학사 이름 및 지원장학 방문 일시 추출
   - 다중 행으로 작성된 '학교 현안문제' 및 '교육활동 관련 지원 요청 사항' 취합
3. **업무별 자동 분류 엔진**
   - 교육지원청 9개 과의 실제 담당 업무 키워드를 기반으로 요청 내용을 분석하여 적합한 부서 자동 배정
4. **목적별 탭 구성 및 정렬 기준 적용**
   - **탭 1. 📅 방문 일정**: 담당장학사(오름차순) ➡️ 학교급(고→중→초 내림차순) ➡️ 학교명(오름차순)
   - **탭 2. ⚠️ 학교 현안 문제**: 학교급(내림차순) ➡️ 학교명(오름차순)
   - **탭 3. 💡 교육활동 관련 지원 요청 사항**: 학교급(내림차순) ➡️ 학교명(오름차순)
   - **탭 4. 🏛️ 부서별(9개 과) 업무 분류**: 교육지원청 과(오름차순) ➡️ 학교급(내림차순) ➡️ 학교명(오름차순)
5. **분석 결과 엑셀 일괄 다운로드 (파일명 자동 생성)**
   - 4개 시트(방문일정, 학교현안문제, 지원요청사항, 과별배정결과)로 정리된 단일 엑셀 파일 내보내기 지원
   - 작업 시점의 날짜 및 시간에 맞춰 파일명이 자동 지정됩니다. (예: `202609121445 지원장학 요청서 분류.xlsx`)

## 🏛️ 업무 분류 대상 (교육지원청 9개 과)

* **재정지원과**: 학교회계, 예·결산, 계약 및 지출, 공유재산, 유보통합 재정, 교직원 급여
* **중등교육지원과**: 중·고 교육과정, 교원인사·평정, 고입전형, 진로진학, 체육·예술교육, 순회교사
* **초등교육지원과**: 초등·유치원 교육과정, 기초학력(문해·수리), 특수교육지원센터, AI미래/과학교육
* **평생교육건강과**: 학원·교습소 지도점검, 학교급식 및 보건, 교육환경보호구역 관리
* **학교생활교육과**: 학교폭력 심의 및 전담조사관, 지역교권보호위원회, 학생 마음건강(SEM119)
* **학교시설지원과**: 시설 증·개축 및 교육환경개선 설계/감독, 학교안전점검, 내진보강, 공간재구조화
* **학교통합지원과**: 인력채용(기간제/교육공무직), 체험학습 안전, 디벗/학내망 정보화 지원, 공통위탁용역
* **학생맞춤협력과**: 강서/양천 Wee센터 운영, 학생맞춤통합지원, 위기학생 상담, 난독/경계선 지능 지원
* **행정지원과**: 학생배치계획, 학급편제 및 학구 조정, 청사 관리, 정보보안 및 행정정보화

## 🚀 사용 방법

1. 배포된 웹 앱 페이지(`https://<사용자계정>.github.io/<저장소명>/`)에 접속합니다.
2. (최초 접속 시 브라우저 내부에 가상 환경을 구축하므로 약 10~20초의 로딩 시간이 소요됩니다.)
3. 파일 업로더 영역에 관내 학교들의 지원장학 요청서(`.xlsx`, `.xls`)를 일괄 선택하거나 드래그하여 업로드합니다.
4. 분석이 완료되면 상단 4개의 탭을 통해 정렬된 데이터 및 부서 배정 결과를 확인합니다.
5. 네 번째 탭 하단의 **`📥 엑셀 파일로 일괄 다운로드`** 버튼을 눌러 결과 파일을 다운로드합니다.

## 🛠️ 기술 스택 (Tech Stack)

* **Runtime**: [stlite](https://github.com/whitphx/stlite) (WebAssembly-powered Streamlit in the browser)
* **Frontend/Framework**: Streamlit Python Library
* **Data Processing**: Pandas, OpenPyXL, xlrd
* **Hosting**: GitHub Pages (Serverless / Static HTML)

---

## 🔒 개인정보 및 보안 안내

본 웹 앱은 외부 서버로 데이터를 전송하지 않으며, 사용자의 기기(Client-side WebAssembly) 내에서만 파일 파싱 및 데이터 처리가 이루어집니다. 관내 학교의 현안이나 행정 문서 내용이 외부 서버에 임시로라도 저장되거나 유출되지 않으므로 안심하고 사용할 수 있습니다.
